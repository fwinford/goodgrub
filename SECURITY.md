# Reporting a security vulnerability

If you believe you have found a security vulnerability in GoodGrub, please
report it privately to [goodgrubsupport@gmail.com](mailto:goodgrubsupport@gmail.com)
instead of opening a public GitHub issue with vulnerability details. We
encourage responsible private reporting so the project can assess a report
before details are shared publicly.

To help with an investigation, include the affected GoodGrub version or commit,
steps to reproduce the issue, its potential impact, and any relevant supporting
evidence. Please sanitize logs, screenshots, and other evidence before sending.

Do not send passwords, credentials, access tokens, signing material, private
keys, or unnecessary personal information.
